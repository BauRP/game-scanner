# Game Scanner 🎮

Автоматический Telegram-канал о компьютерных играх на бесплатных Cloudflare Workers, Workers AI и D1. Компьютер владельца может быть выключен.

## Что умеет

- Читает RSS-новости из 15 игровых источников (16 RSS/Atom-лент). Недоступность одного источника не останавливает остальные.
- Выбирает новые материалы, проверяет время публикации, не повторяет отправленные ссылки.
- Пишет короткие новости на русском через Cloudflare GPT-OSS 20B. Если GPT-OSS 20B недоступен или выдаёт неподходящий текст, пробует Gemma 4 26B A4B через тот же Cloudflare Workers AI. Если ИИ недоступен, публикация не выполняется: заголовок источника не выдаём за текст ИИ.
- Публикует в Telegram фото с русскоязычным заголовком и текстом без видимой подписи источника. Первоисточник проверяется и хранится внутри системы, но ссылка и название издателя не показываются подписчикам. Приоритет — проверенное оригинальное изображение, резерв — собственная обложка.
- Сохраняет историю в D1. Таблицы создаются при первом включённом запуске.
- Запускается каждый час, до 24 разных новостей за период 05:00–05:00 по времени Казахстана. При отсутствии достоверной новости час пропускается.
- Открытый /health показывает статус. Ручной /run защищён ADMIN_KEY.

Почасовая публикация запрошена владельцем; реальная отправка защищена однократной проверкой обоих ИИ. Никогда не храните токен Telegram или ключ Groq в публичном GitHub.

## Шаги в Cloudflare

1. Workers & Pages → Create → Connect GitHub → BauRP/game-scanner.
2. Имя game-scanner, Build command пусто, Deploy command npx wrangler deploy, затем Deploy. Wrangler 4.45+ автоматически создаёт D1 без ID в конфигурации.
3. Открыть адрес Worker с /health; ожидается publishing:true после развёртывания почасовой версии; готовность обоих ИИ проверяется через /commissioning-status.
4. Worker → Settings → Variables and Secrets: добавить тип Secret:
   - TELEGRAM_BOT_TOKEN = НОВЫЙ токен от BotFather (старый был опубликован, его использовать нельзя);
   - TELEGRAM_CHAT_ID = настоящий @адрес публичного КАНАЛА, не бота;
   - Резервная Gemma использует существующую привязку AI и не требует отдельного ключа;
   - ADMIN_KEY = необязательный длинный случайный пароль для ручного запуска;
5. После подключения секретов в GitHub изменить PUBLISH_ENABLED в wrangler.jsonc с false на true и сохранить. Cloudflare автоматически развернёт код. Для остановки вернуть false.
6. Проверка: /health, ошибки: Worker → Logs.

## Изображения и права

- Посты отправляются через Telegram sendPhoto. Сначала программа ищет изображение из RSS или Open Graph оригинальной статьи. Если изображение отсутствует, URL небезопасен или Telegram отверг изображение HTTP 400, отправляется собственная обложка Game Scanner.
- USE_SOURCE_IMAGES=true в конфигурации по запросу владельца. Изображения сторонних издательств могут охраняться авторским правом: указание источника не заменяет разрешения; перед открытым коммерческим запуском необходимо оценить условия использования у издательств. Чтобы отключить чужие изображения, установите USE_SOURCE_IMAGES=false: собственная обложка продолжит работать.
- Не копируем целые чужие статьи. Оригинальный URL проверяется по списку доменов издателя и сохраняется в D1 для внутренней проверки и защиты от дублей; он не включается в подпись Telegram-поста. Внутренняя фиксация источника не заменяет разрешения на использование защищённого изображения; соблюдайте условия издателя.

## Ограничения

- Если свежих достоверных новостей нет, посты не выдумываются.
- Обе модели делят квоту Workers AI аккаунта Game Scanner. По информации владельца Kaz AI находится в отдельном аккаунте.
- После сомнительного ответа Telegram отправка повторно не запускается для предотвращения дублей.
- wrangler.jsonc является источником настроек, не добавляйте туда секреты.

npm install, npm test, npm run check. Для локального режима: npm run dev.

Kaz AI не меняется.

## Безопасная проверка GPT-OSS 20B

После развёртывания откройте /ai-preview, введите ADMIN_KEY и нажмите «Проверить ИИ на одной новости».
Результат доступен по /ai-preview-status и сохраняется в D1. Это одна попытка, без публикации в Telegram.
Модель должна использовать только заголовок и короткий отрывок проверенного RSS-источника.
16 редакционных категорий и фильтр качественных бесплатных игр находятся в src/editorial.js.
Числа, которых нет в исходном материале, не допускаются; слухи требуют явной оговорки.
Автоматическая публикация зависит от PUBLISH_ENABLED и результата проверки обеих моделей.

## Два ИИ и обязательное фото

Основная модель: `@cf/openai/gpt-oss-20b`; запасная: `@cf/google/gemma-4-26b-a4b-it`. Обе работают через binding AI, без Groq. Порядок автоматический, если основная модель недоступна или выдаёт непригодный результат. Обе модели расходуют бесплатную общую квоту Workers AI текущего аккаунта Cloudflare.

Каждый новостной пост отправляется через `sendPhoto` с русскоязычным заголовком и текстом без отдельной строки источника, а не обычным `sendMessage`. При отсутствии допустимого изображения сайт-источник не запрашивается бесконечно, вместо него загружается собственная картинка Game Scanner. Если Telegram не подтвердил отправку или сетевой результат неоднозначен, повтор не выполняется, чтобы избежать дублей.

Автопубликация запрошена: `PUBLISH_ENABLED=true`, но до подтверждения двух моделей обычные посты блокируются. Проверка черновика: `/ai-preview`.

## Однократная проверка перед запуском

При `COMMISSION_ONCE=true` и `PUBLISH_ENABLED=false` следующий плановый запуск проверит обе модели отдельно и отправит не более одной настоящей новости только с оригинальным изображением. Результат: GET /commissioning-status. POST /commission-once требует существующий ADMIN_KEY. При неопределённой доставке повтор блокируется. Если `PUBLISH_ENABLED=true`, обычная публикация при включённом режиме проверки допускается только после сохранённого подтверждения обеих моделей и сообщения Telegram с оригинальным фото. Настройки плановой рассылки: 0 * * * *, максимум 24 за сутки. Не отключайте защиту до проверки результата. Если проверка ещё не завершена, почасовой запуск может выполнить оставшуюся безопасную попытку проверки. Статистика источников: /source-quality. Защита от повторов учитывает ссылки, совпадающие нормализованные заголовки за 72 часа и одну зарезервированную попытку на час.

## Переводчик

Заголовок и текст каждой новости должны быть на русском. Названия игр, платформ и компаний сохраняются в оригинале. GPT-OSS выполняет перевод и редактирование за один запрос; при непригодном переводе используется Gemma. Если обе модели не дают допустимый русский текст, эта новость пропускается. Повторная проверка перед Telegram не допускает отправку английской новости. Обычная реклама сувениров не считается игровым релизом. /health показывает версию политики перевода. Новые служебные действия требуют ADMIN_KEY.
