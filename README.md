# Game Scanner 🎮

Автоматический Telegram-канал о компьютерных играх на бесплатных Cloudflare Workers, Workers AI и D1. Компьютер владельца может быть выключен.

## Что умеет

- Читает RSS-новости из четырёх игровых источников. Недоступность одного источника не останавливает остальные.
- Выбирает новые материалы, проверяет время публикации, не повторяет отправленные ссылки.
- Пишет короткие новости на русском через Cloudflare GPT-OSS 20B. Если GPT-OSS 20B недоступен или выдаёт неподходящий текст, пробует Gemma 4 26B A4B через тот же Cloudflare Workers AI. Если ИИ недоступен, публикация не выполняется: заголовок источника не выдаём за текст ИИ.
- Публикует в Telegram со ссылкой на первоисточник. Часто Telegram показывает превью статьи с картинкой. При наличии собственного DEFAULT_PHOTO_FILE_ID отправляет его с текстом.
- Сохраняет историю в D1. Таблицы создаются при первом включённом запуске.
- Запускается каждые три часа, до 8 разных новостей за сутки по времени Казахстана.
- Открытый /health показывает статус. Ручной /run защищён ADMIN_KEY.

По умолчанию публикация ВЫКЛЮЧЕНА! Никогда не храните токен Telegram или ключ Groq в публичном GitHub.

## Шаги в Cloudflare

1. Workers & Pages → Create → Connect GitHub → BauRP/game-scanner.
2. Имя game-scanner, Build command пусто, Deploy command npx wrangler deploy, затем Deploy. Wrangler 4.45+ автоматически создаёт D1 без ID в конфигурации.
3. Открыть адрес Worker с /health; ожидается publishing:false.
4. Worker → Settings → Variables and Secrets: добавить тип Secret:
   - TELEGRAM_BOT_TOKEN = НОВЫЙ токен от BotFather (старый был опубликован, его использовать нельзя);
   - TELEGRAM_CHAT_ID = настоящий @адрес публичного КАНАЛА, не бота;
   - Резервная Gemma использует существующую привязку AI и не требует отдельного ключа;
   - ADMIN_KEY = необязательный длинный случайный пароль для ручного запуска;
   - DEFAULT_PHOTO_FILE_ID = необязательный идентификатор собственной фотографии, загруженной в Telegram.
5. После подключения секретов в GitHub изменить PUBLISH_ENABLED в wrangler.jsonc с false на true и сохранить. Cloudflare автоматически развернёт код. Для остановки вернуть false.
6. Проверка: /health, ошибки: Worker → Logs.

## Изображения и права

- Посты отправляются через Telegram sendPhoto. Сначала программа ищет изображение из RSS или Open Graph оригинальной статьи. Если изображение отсутствует, URL небезопасен или Telegram отверг изображение HTTP 400, отправляется собственная обложка Game Scanner.
- Свое фото можно задать через DEFAULT_PHOTO_FILE_ID, тогда оно отправляется в каждом посте.
- USE_SOURCE_IMAGES=true в конфигурации по запросу владельца. Изображения сторонних издательств могут охраняться авторским правом: указание источника не заменяет разрешения; перед открытым коммерческим запуском необходимо оценить условия использования у издательств. Чтобы отключить чужие изображения, установите USE_SOURCE_IMAGES=false: собственная обложка продолжит работать.
- Не копируем целые чужие статьи, всегда указываем источник.

## Ограничения

- Если свежих достоверных новостей нет, посты не выдумываются.
- Квоты Cloudflare и Groq ограничены; Workers AI в одном аккаунте делит квоту с Kaz AI.
- После сомнительного ответа Telegram отправка повторно не запускается для предотвращения дублей.
- wrangler.jsonc является источником настроек, не добавляйте туда секреты.

## Безопасная проверка GPT-OSS 20B

После развёртывания откройте /ai-preview, нажмите «Проверить ИИ на одной новости».
Результат доступен по /ai-preview-status и сохраняется в D1. Это одна попытка, без публикации в Telegram.
Модель должна использовать только заголовок и короткий отрывок проверенного RSS-источника.
16 редакционных категорий и фильтр качественных бесплатных игр находятся в src/editorial.js.
Числа, которых нет в исходном материале, не допускаются; слухи требуют явной оговорки.
Автоматическая публикация по-прежнему выключена (PUBLISH_ENABLED=false).

## Два ИИ и обязательное фото

Основная модель: `@cf/openai/gpt-oss-20b`; запасная: `@cf/google/gemma-4-26b-a4b-it`. Обе работают через binding AI, без Groq. Порядок автоматический, если основная модель недоступна или выдаёт непригодный результат. Обе модели расходуют бесплатную общую квоту Workers AI текущего аккаунта Cloudflare.

Каждый новостной пост отправляется через `sendPhoto` с подписью и ссылкой на источник, а не обычным `sendMessage`. При отсутствии допустимого изображения сайт-источник не запрашивается бесконечно, вместо него загружается собственная картинка Game Scanner. Если Telegram не подтвердил отправку или сетевой результат неоднозначен, повтор не выполняется, чтобы избежать дублей.

Автопубликация остаётся отключена: `PUBLISH_ENABLED=false`. Проверка черновика: `/ai-preview`.

## Однократная проверка перед запуском

При `COMMISSION_ONCE=true` и `PUBLISH_ENABLED=false` следующий плановый запуск проверит Gemma отдельно и отправит не более одной настоящей новости только с оригинальным изображением. Результат: GET /commissioning-status. POST /commission-once требует существующий ADMIN_KEY. При неопределённой доставке повтор блокируется. Если `PUBLISH_ENABLED=true`, обычная публикация при включённом режиме проверки допускается только после сохранённого подтверждения Gemma и сообщения Telegram с оригинальным фото. Настройки плановой рассылки: 0 */3 * * *, максимум 8 за сутки. Не отключайте защиту до проверки результата.
