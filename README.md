# Game Scanner 🎮

Автоматический Telegram-канал о компьютерных играх на бесплатных Cloudflare Workers, Workers AI и D1. Компьютер владельца может быть выключен.

## Что умеет

- Читает RSS-новости из четырёх игровых источников. Недоступность одного источника не останавливает остальные.
- Выбирает новые материалы, проверяет время публикации, не повторяет отправленные ссылки.
- Пишет короткие новости на русском через Cloudflare GPT-OSS 20B. Использует Groq как запасной ИИ, если добавлен GROQ_API_KEY. При отсутствии ИИ делает краткий текст по заголовку источника.
- Публикует в Telegram со ссылкой на первоисточник. Часто Telegram показывает превью статьи с картинкой. При наличии собственного DEFAULT_PHOTO_FILE_ID отправляет его с текстом.
- Сохраняет историю в D1. Таблицы создаются при первом включённом запуске.
- Запускается каждые три часа, до 8 разных новостей за сутки по времени Казахстана.
- Открытый /health показывает статус. Ручной /run защищён ADMIN_KEY.

По умолчанию публикация ВЫКЛЮЧЕНА! Никогда не храните токен Telegram или ключ Groq в публичном GitHub.

## Шаги в Cloudflare

1. Workers & Pages → Create → Connect GitHub → BauRP/game-scanner.
2. Имя game-scanner, Build command пусто, Deploy command npx wrangler deploy, затем Deploy. Wrangler 4.45+ автоматически создаёт D1 без ID в конфигурации.
3. Открыть адрес Worker с /health; ожидается publishing:false.
4. Worker → Settings → Variables and Secrets: добавить тип Secret:
   - TELEGRAM_BOT_TOKEN = НОВЫЙ токен от BotFather (старый был опубликован, его использовать нельзя);
   - TELEGRAM_CHAT_ID = настоящий @адрес публичного КАНАЛА, не бота;
   - GROQ_API_KEY = необязательный ключ резервного ИИ;
   - ADMIN_KEY = необязательный длинный случайный пароль для ручного запуска;
   - DEFAULT_PHOTO_FILE_ID = необязательный идентификатор собственной фотографии, загруженной в Telegram.
5. После подключения секретов в GitHub изменить PUBLISH_ENABLED в wrangler.jsonc с false на true и сохранить. Cloudflare автоматически развернёт код. Для остановки вернуть false.
6. Проверка: /health, ошибки: Worker → Logs.

## Изображения и права

- По умолчанию отправляется текст со ссылкой. Картинка в Telegram-превью зависит от сайта, не гарантирована для каждой новости.
- Свое фото можно задать через DEFAULT_PHOTO_FILE_ID, тогда оно отправляется в каждом посте.
- USE_SOURCE_IMAGES=false по умолчанию: автоматически копировать чужие изображения без разрешения нельзя. Включать только после проверки прав.
- Не копируем целые чужие статьи, всегда указываем источник.

## Ограничения

- Если свежих достоверных новостей нет, посты не выдумываются.
- Квоты Cloudflare и Groq ограничены; Workers AI в одном аккаунте делит квоту с Kaz AI.
- После сомнительного ответа Telegram отправка повторно не запускается для предотвращения дублей.
- wrangler.jsonc является источником настроек, не добавляйте туда секреты.
